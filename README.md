# ¿Qué juego hoy?

## Descripción del proyecto

“¿Qué juego hoy?” es un catálogo web responsive de juegos de mesa desarrollado únicamente con HTML5 y CSS3.

El objetivo del proyecto es permitir a los usuarios descubrir juegos de mesa mediante un catálogo visual organizado por:
- dificultad
- cantidad de jugadores
- tipo de experiencia

El sitio incluye un sistema de filtrado implementado completamente en CSS puro, sin utilizar JavaScript.

---

# Objetivos del proyecto

- Crear una interfaz moderna y responsive.
- Aplicar buenas prácticas de HTML semántico.
- Utilizar CSS Grid y Flexbox.
- Implementar lógica de filtrado sin JavaScript.

---

# Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts
